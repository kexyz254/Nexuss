# ADR-0002: Build a Vertical Slice Before Broad Expansion

**Status:** Proposed  
**Classification:** Confidential  
**Owner:** kexyz254peter

## Context

Nexuss has a wide long-term vision. Building many incomplete connectors would create a hype prototype without proving trust, verification, or recovery.

## Decision

Implement the Daily Operations Command as the first complete vertical slice before adding broad application control.

## Consequences

- Slower feature-count growth.
- Faster validation of the real architecture.
- Reusable contracts for later capabilities.
