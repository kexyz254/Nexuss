# P6.8A Threat Model

## Protected assets

- Gmail content
- Calendar event details
- Contact information
- Mobile communication signals
- OAuth access and refresh tokens
- Inferred commitments and deadlines

## Controls

- Desktop OAuth authorization-code flow with PKCE
- System browser, never an embedded web view
- Loopback callback with state validation
- DPAPI-encrypted token storage
- Read-only Google scopes
- Bounded retrieval windows and counts
- Local authenticated API boundary
- Source evidence and confidence on every commitment
- No external provider write implementation
- No credentials in API models, logs, receipts, or UI payloads
