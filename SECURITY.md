# Security Policy

**CONFIDENTIAL - NEXUSS AI - kexyz254peter**

## Reporting

Report suspected vulnerabilities privately to the project owner. Do not disclose them publicly.

## Mandatory controls

- No credentials or API tokens in source control.
- No production data in tests.
- All external input is untrusted.
- Device and connector calls require typed contracts.
- High-risk operations fail closed.
- Security findings block release according to severity.
