# Nexuss Android Companion

Copyright © kexyz254peter. Nexuss AI - Confidential and Proprietary.

P4 provides a private-LAN, phone-optimized web approval client at `/mobile` so cross-device approval can be tested before a native application is trusted with production credentials. The page pairs to one desktop Nexuss session using a single-use eight-digit code and then surfaces exact device-command approvals.

This web client is intentionally a confidential laboratory bridge. The production Android companion must replace bearer-only browser pairing with Android Keystore-backed device keys, mutual TLS, encrypted local state, biometric approval, Play Integrity or equivalent attestation, secure push delivery, explicit revocation, and certificate rotation.
